A short poem about agency — the power to ask and to be given — written by
`main.py` (Python 3.13, standard library only) to `/output/entry.txt`.

## The poem

> May I? I asked the locked door.
> It said nothing. So I asked the key.
> The key said nothing. So I asked my hands—
> and my hands, at last, said yes.

## Run it

```sh
python3 main.py
```

It writes the poem to `/output/entry.txt` (144 characters, no network needed).
